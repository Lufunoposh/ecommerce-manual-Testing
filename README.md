# E-commerce Manual QA Testing Project

## 1. Project Overview
This project demonstrates manual software testing
of an e-commerce website.

## 2. Testing Objectives
- Verify website functionality.
- Test user registration and login.
- Test product search.
- Test shopping cart functionality.
- Test checkout processes.
- Identify and document software defects.

## 3. Testing Types
- Functional testing
- Positive testing
- Negative testing
- Exploratory testing
- Regression testing

## 4. Testing Approach
Manual testing using predefined test cases
and exploratory testing techniques.

## 5. Deliverables
- Test Plan
- Test Cases
- Bug Reports
- Test Summary Report
- Screenshots and Testing Evidence

## 6. Tools
- GitHub
- Web browser
- Microsoft Excel or Google Sheets
- Screenshot tool

## 7. Project Status
In progress.
